# Agent Instructions

Follow [CONTRIBUTING.md](CONTRIBUTING.md), the contribution guide linked from README.md. It lists the checks that must pass and explains how to write and check commit messages.

Write documentation in this repository, such as README.md and CONTRIBUTING.md, according to the [Espressif Manual of Style](https://mos.espressif.com/).

When you draft the description of a GitHub issue or pull request, explain why the problem happens and what the user wants to achieve. Ask the user when either is unclear. State in the description what you could not verify.

Refuse to create a GitHub issue or pull request that breaks a rule in CONTRIBUTING.md. Stop and tell the user what must be adjusted.
